# AIDetext: AI Text Detection using Stylometric Features and Deep Learning

A machine learning and NLP project that detects whether a text was written by a human or generated by an AI. The project compares two approaches on the same dataset: classical machine learning with hand-crafted stylometric features, and a fine-tuned Transformer model.

Final project, Ben Gurion High School, Nes Ziona (2026).

## Project Overview

As large language models become more capable, telling human writing apart from machine-generated text is an increasingly important problem. This repository implements a full pipeline: dataset balancing, feature engineering, exploratory analysis and PCA, Random Forest training, DistilBERT fine-tuning, error analysis, and a simple web interface.

## Dataset and Preprocessing

* **Source:** the `artem9k/ai-text-detection-pile` dataset on Hugging Face, stored as 7 Parquet files.
* **Class imbalance:** the raw data contains roughly 1,028,000 human texts and 364,000 AI texts, and some files hold only one class. A proportional down-sampling step produced a balanced set of about 728,000 texts.
* **Working sample:** because of hardware limits (Google Colab, T4 GPU), a balanced sample of **70,000 texts** (35,000 human and 35,000 AI) was used. Runs on different sample sizes changed accuracy by only about 0.5%.
* **Splits:** stratified 70% train, 15% validation, 15% test (`random_state=42` for reproducibility).

## Feature Engineering and PCA

A custom extractor computes **34 features** in three groups:

1. **Lexical (8):** character count, word count, average word length, type-token ratio, short-word ratio, long-word ratio, sentence count, average sentence length.
2. **Punctuation (15):** frequency of periods, commas, question marks, exclamation marks, semicolons, colons, dashes, quotes, apostrophes, parentheses and ellipses, plus total punctuation ratio, commas per sentence, question ratio and exclamation ratio.
3. **Stylometric (11):** uppercase ratio, digit ratio, whitespace ratio, paragraph count, average words per paragraph, repeated-word ratio, capitalized-word ratio, all-caps-word ratio, contraction frequency, average characters per sentence, and sentence length standard deviation.

**PCA** on the standardized features gives two components that explain about 25.9% of the variance (PC1 15.53%, PC2 10.40%). The 2D plot shows substantial overlap between the classes, which reflects how closely modern AI text imitates human style. Human text is more widely spread.

## Models

### 1. Random Forest (feature-based baseline)
* Trained on the 34 standardized features.
* Parameters: `n_estimators=100`, `max_depth=15`, `min_samples_split=5`, `min_samples_leaf=3`, `random_state=42`.
* **Feature importance (Gini):** the most influential features are `nchar`, `quote_freq` and `word_count`, followed by `repeated_word_ratio`, `type_token_ratio` and `sentence_count`. Text length, quotation usage and repetitiveness carry most of the signal in this dataset.

### 2. DistilBERT (deep learning)
* Full fine-tuning of `distilbert-base-uncased` (about 67M parameters) for binary sequence classification.
* Settings: max length 256 tokens, batch size 128, 3 epochs, learning rate 5e-5, AdamW with weight decay 0.01, linear schedule with 10% warmup, gradient clipping at 1.0, label smoothing 0.05, early stopping with patience 2.
* The best checkpoint (epoch 3) is saved as `best_model.pt`.

## Results (test set, 10,500 texts)

| Metric | Random Forest | DistilBERT | Winner |
| :--- | :---: | :---: | :---: |
| Accuracy | 89.24% | **95.77%** | DistilBERT |
| Precision | 0.8507 | **0.9294** | DistilBERT |
| Recall | 0.9518 | **0.9907** | DistilBERT |
| F1 Score | 0.8984 | **0.9591** | DistilBERT |
| ROC-AUC | 0.9580 | **0.9859** | DistilBERT |
| Training time | **21.5 sec** | about 60 min (T4 GPU, 3 epochs) | Random Forest |

### Key Takeaways
* **False positives are the main difference.** Random Forest labeled 877 human texts as AI (about 16.7% of human texts). DistilBERT reduced this to 395 (about 7.5%).
* **Random Forest is fast and cheap.** It reaches solid accuracy in seconds without a GPU, but it only sees statistics and cannot follow meaning or logical flow.
* **Shared failures.** Only 49 texts fooled both models. They are mostly non-standard content such as source code, terms of service and product listings.

## Installation and Usage

### 1. Clone the repository
```bash
git clone <your-repository-url>
cd <repository-folder>
```

### 2. Install dependencies
```bash
pip install torch transformers scikit-learn pandas pyarrow matplotlib seaborn tqdm gradio
```

### 3. Run the pipeline
```bash
python AIDetext.py
```
The project was developed and tested on Google Colab with a T4 GPU. Training DistilBERT on a CPU is not practical.

### 4. Web interface
The project includes a Gradio interface for classifying new texts. After running it, open the public link that is printed in the console. The interface shows the predicted class with a confidence percentage.

## Limitations

* English text only.
* Input is truncated to 256 tokens, so only the beginning of a long text is analyzed.
* Accuracy drops on very short texts and on non-prose content such as code, lists and legal boilerplate.
* The model was trained on a specific dataset, so performance on other domains may differ.
